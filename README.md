# Mihon [应用](#)

### 功能齐全的阅读器

在你的 Android 设备上，以前所未有的便捷方式发现并阅读漫画、条漫（Webtoon）、美漫等各类内容。

## 功能特性

<div align="left">

- 本库与上游的核心区别仅为把插件安装到应用私有目录，不再交给系统安装器。修改为AI实现，因为钱包问题不会随时同步上游修改，随缘更新。因为厌恶国产系统对安装程序的限制所做的修改，更适合中国宝宝的体质。



- 支持本地内容的阅读。
- 可高度配置的阅读器，提供多种阅读模式、阅读方向以及其他设置。
- 支持追番/进度同步服务：[MangaBaka](https://mangabaka.org)、[MyAnimeList](https://myanimelist.net/)、[AniList](https://anilist.co/)、[Kitsu](https://kitsu.app/)、[MangaUpdates](https://mangaupdates.com)、[Shikimori](https://shikimori.one)、[Bangumi](https://bgm.tv) 以及 [Hikka](https://hikka.io/)。
- 通过分类功能整理你的书库。
- 提供浅色与深色主题。
- 可定时检查书库更新，获取最新章节。
- 可在本地创建备份以便离线阅读，或备份到你所选用的云服务。
- 还有更多功能……

</div>
