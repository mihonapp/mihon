# Mihon [App](#)

This fork is mostly for personal customization.

## Download

Download the latest APK from the [Releases](https://github.com/alias-rgb/mihon/releases) page.

## Extra Features

<div align="left">

Tuned for reading manhwa and webtoons on large tablets like the Galaxy Tab S7.

Based on Mihon v0.20.1, so it works with current extension stores (TachiyomiX 1.6 extensions), such as Keiyoushi.

### Reader
- Vertical seekbar for vertical reading modes, on either side, optionally in landscape too. It fills exactly the
  space between the reader's top and bottom bars.
- Tapping to scroll a long strip moves by the window's height, so it's right in split screen and pop-up view.
- Online chapters load several pages in parallel around the page you're reading, instead of one at a time.

### Other
- App updates come from this fork's releases, not upstream Mihon's.
- Tokyo Night theme, and Catppuccin / Nord theme fixes.
- Selected fixes from upstream Mihon: long strip zoom and layout fixes, crash fixes for WebView and library
  range selection, backup restore fixes and more (see the [changelog](CHANGELOG.md)).
- No in-app donation prompts, and no `(╬ಠ益ಠ)` error face on empty screens.
