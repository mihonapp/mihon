## Lightweight final-package rerun

`scripts/verify-packaged-reader-artifact.ps1` implements the existing verifier's assertion contract without its Gradle/build/cleanup steps. It requires a new output directory/profile, protects existing evidence, runs hidden independent EXE processes, and compares hashes before and after execution. To check the final rebuilt package with the retained fixture:

```powershell
./scripts/verify-packaged-reader-artifact.ps1 `
  -Launcher './desktop-app/build/compose/binaries/main/app/MihonW/MihonW.exe' `
  -FixtureRoot './desktop-app/build/verification/suwayomi-reader-prerelease-20260915-01/fixture' `
  -OutputRoot './desktop-app/build/verification/suwayomi-reader-final-20260915-01'
```

To generate a fresh fixture at an unused path, run the shared wrapper with `MIHON_W_READER_FIXTURE_DIR` set to that absolute path and filter `mihon.desktop.reader.PackagedReaderScenarioTest.fixture builder*`. Existing fixture directories must not be reused because the builder explicitly requires an empty destination.

GUI screenshots, actual wheel/chrome interaction and any artifact rebuilt after this JAR hash are separate evidence. This report does not claim that headless mode validates those UI behaviors or arbitrary external production content.
